# C1 — Karta produktu Roomly
Roomly to SaaS dla pracowników i administratorów firm zarządzających salami konferencyjnymi.
## Problem i rozwiązanie
Rozproszone rezerwacje powodują konflikty i utrudniają znajdowanie sal. Roomly centralizuje dostępność, sale i rezerwacje we wspólnym kalendarzu.
## Role
Pracownik: przeglądanie sal, kalendarza zajętości, rezerwowanie i anulowanie własnych przyszłych spotkań, profil.
Administrator organizacji: funkcje pracownika, zarządzanie salami, rezerwacjami, zespołem, rolami i statystykami. Nie zarządza cudzą firmą.
## Model SaaS
Basic: 19 zł / użytkownik / miesiąc — sale, rezerwacje, kalendarz i podstawowa administracja.
Pro: 39 zł / użytkownik / miesiąc — Basic, rozbudowane statystyki i analiza wykorzystania.
Cennik jest koncepcyjny. Płatności nie są zaimplementowane; aktualne MVP nie ogranicza funkcji według planu.
Usługa kupowana jako gotowa: Lovable Cloud — PostgreSQL, uwierzytelnianie i środowisko uruchomieniowe.
