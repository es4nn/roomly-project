# Audyt demo — osiem punktów
1. Dwa fikcyjne zasoby i trzy fikcyjne rezerwacje startowe; bez danych rzeczywistych.
2. Stan istnieje tylko w pamięci bieżącej strony; po odświeżeniu wracają rekordy startowe.
3. Wybór roli jest symulacją, nie uwierzytelnianiem.
4. Ukryte przyciski administracji można obejść narzędziami przeglądarki.
5. Nie ma serwera, RLS ani prawdziwego rozdzielenia organizacji.
6. Kontrola konfliktów działa wyłącznie w jednej pamięci przeglądarki; nie chroni wielu użytkowników.
7. Nie ma backupu, trwałego audytu ani eksportu; utrata danych jest oczekiwana.
8. Pliki nie zawierają kont produkcyjnych ani sekretów i nie mogą obsługiwać rzeczywistych firm.
